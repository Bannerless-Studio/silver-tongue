# Vendored assets

Generated by make-it-in-china tools/blender/build_all.py (GLBs) and tools/blender/town_layout.py
(`town_layout/town.json`, `landscape/terrain_town_walkable.json`); do not hand-edit. Only the GLBs
`src/layout.json` and `src/town.json` use, plus an `index.json` listing only those, and the town's
sources that `scripts/port-town.mjs` turns into `src/town.json`. `audio/`: tools/audio/owner_theme.py (music) and
tools/audio/make_audio.py (ambience and effects; .ogg + .m4a, metadata, and manifest.json). `ui/title/`: the title screen's
backdrop, the fly-over's frames (town_layout/cutscene_frames) as JPEG q80.

Regenerate with `npm run assets:sync -w @silver-tongue/world3d` (copies from `WORLD3D_ASSETS`,
default `../assets` next to the repo checkout, and re-ports the town).
