# B3 slice 3: all of HSK 1, and money balance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `silver-tongue@0.11.0`, in which every HSK 1 word is in at least 3 scenes (the build enforces it) and money is tight but fair.

**Architecture:**
- **Core:** one rule change. A right reply earns `payFor(ex.pay, run.misses)`: full pay with no misses, half after one miss, nothing after two.
- **Bots:** they report rent-late nights, total earned, total spent at the shop, and the lowest wallet after rent. When rent is close and money is short, they put paid work ahead of story.
- **Content:** 17 new scenes in two new places (a tea house and a stairwell) and three existing ones (school, station, room), plus the hospital and the noodle shop. There is one edit to an old line, two new notes, and `checks.coverage: true`.
- **Pay:** tuned against CI rules on the bots.

**Tech Stack:** TypeScript, Vitest, Fluent content, npm workspaces.

**Spec:** `docs/superpowers/specs/2026-09-26-b3-3-hsk1-coverage-economy-design.md`

```ts
/**
 * What a right reply earns: the full pay on the first try, half (rounded down) after one miss,
 * nothing once the person has had to rephrase (two misses). Spec: wrong answers leave you short.
 */
export function payFor(pay: number, misses: number): number {
  if (misses <= 0) return pay;
  if (misses === 1) return Math.floor(pay / 2);
  return 0;
}
```
