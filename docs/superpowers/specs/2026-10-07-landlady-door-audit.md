## Astra review fixes

1. **Lab isolation:** `doorExperimentOn` gates both runtime photo behavior and persistence from the page's `labMode()` flag. Non-lab games never load, clear, save or expose photo state, never render the Book photograph, and always follow the same name-only stall path. Shared narration no longer refers to a photograph on that path. Both friendship choices are tested before and after reload with a deliberately injected stale photo store.
2. **Stale saves:** this experiment's single `DOOR_LAB_PREFIX` constant is `silver-tongue-lab-door:`. `labKeyValue` accepts an explicit namespace while retaining its existing default for other experiments. All sessions, settings, desk/paper positions, counters, hints and opening records now share the new namespace. Tests seed old lab data on the same origin and verify that none is read, overwritten or migrated.
3. **Farewell:** Park remains at the bench and says `안녕히 가세요.`; the leaving player replies `안녕히 계세요.`. English meanings remain “Goodbye.”; the reply intent now specifies leaving Park. Existing yes/no distractors retain their meanings and use only met vocabulary. Korean tagging was regenerated from the course builder.
4. **Question spoiler:** the start of street-again and the end of street-introductions describe speed or gesture without explaining the question. `asked-where` remains feedback after an attempted reply, not advance narration.
5. **Book empty state:** one document view gathers core-kept papers, all desk papers and the lab photograph. Both rendering and “Nothing yet” use that view. Tests cover each source alone and a truly empty Book.
